# Homebrew tap

Homebrew formulae and casks by flotttt.

## SonyNotch

Control Sony headphones from your Mac's menu bar and notch. See [SonyNotch](https://github.com/flotttt/SonyNotch).

```sh
brew install --cask flotttt/tap/sonynotch
```

Update with `brew upgrade --cask sonynotch`, uninstall with `brew uninstall --cask sonynotch`.

The cask is updated automatically when a new SonyNotch release is published.
